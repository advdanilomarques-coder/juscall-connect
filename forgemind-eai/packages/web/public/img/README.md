# Suas fotos reais (opcional)

A landing usa arte SVG/CSS por padrão (funciona 100% offline). Se quiser **fotos
reais de tecnologia**, solte arquivos `.jpg` aqui com estes nomes — eles aparecem
automaticamente nos cards, sobre a arte. Sem o arquivo, a arte continua.

Nomes usados pelos cards:

- `inline.jpg`    — Ghost Text / Inline
- `agent.jpg`     — Agente de projetos grandes
- `terminal.jpg`  — Terminal AI
- `memory.jpg`    — Memória & histórico
- `privacy.jpg`   — Privado e offline
- `hybrid.jpg`    — Híbrido

Dica: imagens ~800×500px, otimizadas (< 200 KB cada) para não pesar o site.
Como tudo é local, as fotos ficam só na sua máquina.

Depois de adicionar, rode `npm run build:web` e recarregue o site.
