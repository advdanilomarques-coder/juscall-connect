# Changelog

Todas as mudanças relevantes do PedroIA serão documentadas aqui.
O formato segue [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/).

## [0.1.0] - 2026-08-02

### Adicionado
- 💬 Painel de chat com streaming em tempo real.
- 🧠 Comando "Explicar seleção" no menu de contexto do editor.
- ⚡ Autocomplete inline estilo Copilot (todas as linguagens).
- ⚙️ Configurações: `backendUrl`, `apiKey`, `enableAutocomplete`, `autocompleteDebounceMs`.
- ⌨️ Atalho `Ctrl+Alt+P` / `Cmd+Alt+P` para abrir o chat.
